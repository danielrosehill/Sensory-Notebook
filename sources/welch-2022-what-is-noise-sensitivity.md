# Welch D, Dirks KN, Shepherd D, Ong J

A conceptual review arguing that noise sensitivity is not adequately captured as one simple trait. It reframes it as the process by which a sound comes to be experienced as noise. It notes that sounds which break the expected acoustic range of a setting are tolerated worse than those that fit it, which bears on noise intruding into a home. Read in part via full-text search.
