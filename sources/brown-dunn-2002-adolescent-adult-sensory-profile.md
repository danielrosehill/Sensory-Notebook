# Brown C, Dunn W

A commercial 60-item self-report trait measure of sensory processing for ages 11+, built on Dunn's model crossing neurological threshold with behavioural response. It yields four quadrants (low registration, sensation seeking, sensory sensitivity, sensation avoiding), each scored 15–75 against age norms, and spans multiple modalities including auditory, touch and taste/smell. It is the instrument used in the adult ADHD sensory literature (Bijlenga 2017) and the only listed measure that tests a cross-modal SOR pattern. Product-page and secondary reading.
