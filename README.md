# Sensory Notebook

An open, running notebook about **sensory sensitivity** — half research, half lived experience.

I ask questions about how sensory processing works and what the evidence actually supports;
Claude writes longform, sourced answers; the pairs accumulate here in the open. Alongside
that sit my own notes — my sensory profile, how I came to understand it, and the specific
things that have and haven't worked for me over the years.

The two halves are deliberately kept apart. Anything presented as a **finding** cites a
source. Anything presented as a **recommendation** is one person's experience, reported as
such, with the failure modes included.

> **Not medical advice.** I'm not a clinician. This is a personal notebook published in
> case it's useful to someone else navigating the same thing. Sensory terminology is
> genuinely contested across DSM-5-TR, ICD-11 and the occupational-therapy literature, and
> where that's true I try to say so rather than pick a side quietly.

## Layout

| Path | What's in it |
|---|---|
| `questions/` | One file per question asked, `YYMMDD-<slug>.md` |
| `answers/` | The longform response to each, same slug |
| `recommendations/` | Things I've actually tried, with a verdict and what they didn't fix |
| `context/` | `profile.md` — my sensory profile; `story.md` — how I got here; `scope.md` — what this notebook covers |
| `sources/` | Logged sources referenced from answers |
| `outputs/` | Consolidated exports and PDFs |
| `notes/` | Scratch thinking, not part of exports |

## How it's built

Scaffolded from the `general-research-workspace` variant of the
[research-space plugin](https://github.com/danielrosehill/Claude-Research-Space-Plugin),
which provides the Q&A logging convention and the consolidation-to-PDF workflow. The
`recommendations/` folder and the research/experience separation are specific to this
notebook.
